# 🐦 Puff‑OS
A tiny, hackable 16‑bit operating system you can understand, remix, and rebuild from scratch.

Puff‑OS is designed for learning, experimentation, and creative hacking.  
It boots instantly, avoids legacy complexity, and gives you full control.

---

## ✨ Features
- Custom bootloader
- Shell with built‑in commands
- Runs on QEMU, VirtualBox, v86, and real hardware
- Fully remixable architecture
