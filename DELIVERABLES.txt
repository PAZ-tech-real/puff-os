================================================================================
                           QUICK START GUIDE
================================================================================

1. Install Tools (1 min):
   sudo apt-get install gcc-aarch64-linux-gnu binutils-aarch64-linux-gnu

2. Build OS (1 min):
   cd /workspaces/os
   ./dev build

3. Flash to Pi5 (2 min):
   ./dev flash /dev/sdb

4. Boot & Enjoy:
   Power on Raspberry Pi 5
   View output on UART at 115200 baud

TOTAL TIME: 5 minutes! 🚀
